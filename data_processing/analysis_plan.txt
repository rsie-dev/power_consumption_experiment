Analysis plan:
1. Preparation
1.1 Define subset
Objective: Select the required operation and threading subset.
Reason: Each analysis requires a clearly defined scope.

1.2 Validate data
Objective: Check completeness, repetitions, duplicates, missing values, and positivity.
Reason: Invalid data can bias results and prevent log transformation.

1.3 Calculate log target
Objective: Log-transform throughput or energy efficiency.
Reason: Effects are expected to be multiplicative; raw outcomes need not be normally distributed.

1.4 Check temporal drift
Objective: Test the target against run order.
Reason: Heating or throttling may affect later trials.

2. Modeling
2.1 Check factorial completeness
Objective: Verify that every factor combination has observations.
Reason: Missing cells can make interaction terms non-estimable.

2.2 Fit full factorial model
Objective: Model the logged target using all main effects and interactions among host, tool, dataset, and strength.
Reason: This captures factors acting individually and in every possible combination.

2.3 Check residuals
Objective: Inspect residual-versus-fitted, Q–Q, and residual-distribution plots.
Reason: Model assumptions concern residuals rather than the raw target.

2.4 Investigate extreme observations
Objective: Identify errors and influential trials.
Reason: Statistical extremeness alone does not justify removal.

3. Inference
3.1 Calculate robust ANOVA
Objective: Test model terms using HC3-robust inference.
Reason: HC3 accommodates unequal residual variance.

3.2 Estimate effects
Objective: Calculate geometric means, ratios, and confidence intervals.
Reason: These show effect direction and practical magnitude.

3.3 Quantify importance
Objective: Calculate \(\omega^2\) for every model term.
Reason: It estimates explained variation while correcting for term complexity and sampling noise.

3.4 Bootstrap importance
Objective: Obtain confidence intervals for each term’s \(\omega^2\) and \(\eta^2\), together with their rank distributions.
Reason: Point estimates cannot show whether effect sizes and apparent rankings are stable.

4. Results
4.1 Rank terms
Objective: Rank main effects and interactions by \(\omega^2\).
Reason: This provides a less biased importance ranking than \(\eta^2\).

4.2 Report results
Objective: Present ranks, effects, uncertainty, and diagnostics.
Reason: Conclusions require both practical magnitude and statistical support.
